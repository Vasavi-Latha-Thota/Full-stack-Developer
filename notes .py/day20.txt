What is OOP?
Object-Oriented Programming (OOP) is a programming paradigm that organizes a
program around objects instead of only functions.
An object is a real-world entity that contains both:
● Attributes (Data): The properties or characteristics of the object.
● Methods (Behavior): The actions or operations that the object can perform.
OOP helps us model real-world entities in software, making programs easier to design,
understand, maintain, and extend.
Flipkart Example
Imagine you are developing an online shopping platform like Flipkart. Every product listed
on Flipkart has information such as:
● Product Name
● Brand
● Price
● Category
● Rating
● Stock
A product can also perform actions such as:
● Display product details
● Check stock availability
● Apply a discount
● Calculate the final price
Instead of storing this information in separate variables and writing unrelated functions, OOP
groups both the data (attributes) and behavior (methods) into a single Product object.
This makes the program more organized and easier to manage.
Why Do We Need OOP?
For small programs, procedural programming is simple and effective.
However, as applications become larger, managing code using only functions becomes
difficult.
Consider an e-commerce application like Flipkart.
It contains:

● Millions of products
● Thousands of sellers
● Millions of customers
● Orders
● Payments
● Delivery partners
● Reviews
● Shopping carts
Managing all these using only variables and functions becomes difficult.
OOP solves this problem by organizing related data and functions into objects.
This results in cleaner, reusable, and scalable code.
Problems with Procedural
Programming
In procedural programming:
● Data and functions are separate.
● Code is often repeated.
● Large programs become difficult to maintain.
● Reusing code becomes challenging.
● Real-world entities are difficult to represent.
● Modifying existing features may affect other parts of the program.
OOP Solution
OOP groups related data and functions into a single unit called an object.
For example, instead of creating separate variables and functions for every Flipkart product,
we define a single Product class and create multiple product objects.
This significantly reduces code duplication and improves maintainability.

Advantages of OOP
1. Modularity
OOP divides a large application into smaller classes.
Each class performs a specific task, making the code easier to understand and maintain.
2. Reusability
A class can be reused multiple times.
For example, the same Product class can be used to create laptops, mobiles, televisions,
watches, and many other products.
3. Scalability
As Flipkart adds new product categories and features, the existing classes can be extended
without rewriting the entire application.
4. Abstraction
Abstraction hides unnecessary implementation details and exposes only the required
functionality.
Users only interact with the features they need without knowing the internal implementation.
5. Encapsulation
Encapsulation combines data and methods into a single unit and protects the data from
unauthorized access.
This improves data security and prevents accidental modification.
6. Inheritance
Inheritance allows one class to acquire the properties and methods of another class.
This promotes code reuse and reduces duplication.
7. Polymorphism
Polymorphism allows the same method to perform different tasks depending on the object
using it.
It makes applications more flexible and easier to extend.

Types of Attributes
Attributes are variables that store information about a class or an object.
There are two types of attributes in Python:
1. Class Attributes
2. Instance Attributes
1. Class Attributes
A class attribute belongs to the class itself.
It is shared by all objects created from that class.
If the value of a class attribute changes, the updated value is reflected in every object unless
an object overrides it.
Flipkart Example
Suppose every product on Flipkart belongs to the same shopping platform.
Instead of storing "Flipkart" separately for every product, we can store it once as a class
attribute.

class Product:

Here, platform is a class attribute.

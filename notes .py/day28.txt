Pandas - Introduction
Pandas is a powerful data manipulation and analysis library for Python.
It is built on top of NumPy and is specifically designed for working with structured (tabular) data.
Pandas provides two primary data structures:
Series - a one-dimensional labeled array (like a single column).
DataFrame - a two-dimensional labeled data structure (like a table or spreadsheet).

With these structures, Pandas allows for efficient data cleaning, filtering, transformation, aggregation, and visualization

-------------------------------

1. Pandas = Excel Software
Just like Excel helps you organize and analyze data with rows and columns, Pandas does the same in Python.

Excel -> Manual data handling

Pandas -> Programmatic and automated data handling in Python

2. Series = A Single Column in Excel
Example: The "Employee Names" column.

It's one-dimensional - just a list of names.

Each name has a row number (index) next to it.

In Pandas, that's a Series.

import pandas as pd

names = pd.Series(["Alice", "Bob", "Charlie"])

3. DataFrame = A Full Table (Sheet)
Example: The full employee record table:

ID	Name	Age	Department
1	Alice	28	HR
2	Bob	32	IT
3	Charlie	26	Finance

This whole table - with rows and columns - is a DataFrame in Pandas.

data = {
    "ID": [1, 2, 3],
    "Name": ["Alice", "Bob", "Charlie"],
    "Age": [28, 32, 26],
    "Department": ["HR", "IT", "Finance"]
}

df = pd.DataFrame(data)

4. Why Use Pandas Instead of Excel?
Imagine you have thousands of rows of data. Doing tasks like:

Finding average age

Filtering by department

Filling missing data

Merging with another file

Sorting by salary

These would take a long time manually in Excel.

But with Pandas, it's just 1-2 lines of Python code:

df[df["Department"] == "IT"]  # Filter all IT employees
df["Age"].mean()              # Find average age

Core Data Structures in Pandas
Pandas provides two main data types:

1. Series (1D Data)
A Series is like a single column in Excel.

It is a one-dimensional labeled array.

Example:

import pandas as pd

data = pd.Series([10, 20, 30, 40])
print(data)

Output:

0    10
1    20
2    30
3    40
dtype: int64

The numbers on the left (0, 1, 2, 3) are the indexes.
The values on the right are the data.

2. DataFrame (2D Data)
A DataFrame is like a full Excel sheet with rows and columns.

It is a two-dimensional table of data.

Example:

import pandas as pd

data = {
    "Name": ["Alice", "Bob", "Charlie"],
    "Age": [25, 30, 22],
    "City": ["Delhi", "Mumbai", "Chennai"]
}

df = pd.DataFrame(data)
print(df)

Output:

      Name  Age    City
0    Alice   25   Delhi
1      Bob   30  Mumbai
2  Charlie   22 Chennai

Chapter 2: Pandas Series
What is a Series?
A Series in Pandas is just like a single column of data - for example, a list of student names, prices of products, or marks in math.

It is:

One-dimensional (like a vertical list),

Has labels (called index) by default (0, 1, 2...),

Can store numbers, text, or even dates.

Think of it Like This:
Imagine a list of marks for 4 students:

Index	Marks
0	85
1	90
2	76
3	92

This is exactly how a Pandas Series works.

Simple Code Example
import pandas as pd

# Creating a Series of marks
marks = pd.Series([85, 90, 76, 92])

print(marks)

Output:
0    85
1    90
2    76
3    92
dtype: int64

On the left: indexes (0, 1, 2, 3)
On the right: data values (marks)
dtype: int64 = data type is integer

Using Custom Index (Labels)
We can give names to indexes (like student names):

import pandas as pd

# Marks with student names
marks = pd.Series([85, 90, 76, 92], index=["Alice", "Bob", "Cathy", "David"])

print(marks)

Output:

Alice    85
Bob      90
Cathy    76
David    92
dtype: int64

Now we can access by name:

print(marks["Bob"])  # Output: 90

Basic Operations with Series
# Increase all marks by 5
print(marks + 5)

# Average mark
print("Average:", marks.mean())

Summary:
Concept	Example
Create Series	pd.Series([10, 20, 30])
Custom Index	pd.Series(data, index=...)
Access by Index	series[0] or series["Bob"]
Operations	series + 5, series.mean()


Chapter 3: Pandas DataFrame
What is a DataFrame?
A DataFrame is like a full Excel sheet or a table in a database.
It is a 2D structure: rows and columns.

Each column is like a Series, and together they form a DataFrame.

Real-Life Analogy:
Imagine a student report table:

Name	Age	Marks
Alice	18	85
Bob	19	90
Charlie	17	78

This is exactly how a Pandas DataFrame looks.

Simple Code Example
import pandas as pd

# Create data using dictionary
data = {
    "Name": ["Alice", "Bob", "Charlie"],
    "Age": [18, 19, 17],
    "Marks": [85, 90, 78]
}

# Create DataFrame
df = pd.DataFrame(data)

print(df)

Output:

      Name  Age  Marks
0    Alice   18     85
1      Bob   19     90
2  Charlie   17     78

Understanding the Parts
Rows: Each record (e.g., one student)

Columns: Fields (Name, Age, Marks)

Index: Numbers 0, 1, 2 by default

Accessing Data in a DataFrame
# Get a single column
print(df["Name"])

# Get first 2 rows
print(df.head(2))

# Get specific cell (row 1, column "Marks")
print(df.loc[1, "Marks"])  # Output: 90

Adding New Data
# Add new column
df["Grade"] = ["A", "A+", "B"]

# Add new row
new_row = {"Name": "David", "Age": 18, "Marks": 88, "Grade": "A"}
df.loc[3] = new_row

print(df)

Useful Functions
Function	Purpose
df.head()	Show first 5 rows
df.tail()	Show last 5 rows
df.info()	Info about data (types, nulls)
df.describe()	Stats summary of numbers
df.columns	List column names
df.shape	(rows, columns) count

Summary:
Feature	Pandas Code
Create	pd.DataFrame(data)
Access column	df["Name"]
Access row	df.loc[0]
Add column	df["New"] = [...]
Add row	df.loc[n] = {...}
Basic info	df.info(), df.describe()

Chapter 4: Data Selection and Filtering in Pandas
Once we have a DataFrame, we often need to:

Select specific columns or rows

Filter data based on conditions

Let's use the same student data:

import pandas as pd

data = {
    "Name": ["Alice", "Bob", "Charlie", "David", "Eva"],
    "Age": [18, 19, 17, 18, 20],
    "Marks": [85, 90, 78, 88, 92]
}

df = pd.DataFrame(data)

1. Selecting Columns
Get a single column:
print(df["Name"])
Output:

0     Alice
1       Bob
2   Charlie
3     David
4       Eva
Name: Name, dtype: object

Get multiple columns:
print(df[["Name", "Marks"]])
Output:

      Name  Marks
0    Alice     85
1      Bob     90
2  Charlie     78
3    David     88
4      Eva     92

2. Selecting Rows
By index using .loc[] (label-based):
print(df.loc[2])  # Row with index 2
Output:

Name     Charlie
Age            17
Marks          78
Name: 2, dtype: object

By index using .iloc[] (position-based):
print(df.iloc[1])  # Second row
Output:

Name     Bob
Age        19
Marks      90
Name: 1, dtype: object

3. Filtering Rows (Using Conditions)
Students who scored more than 85:
print(df[df["Marks"] > 85])
Output:

    Name  Age  Marks
1    Bob   19     90
3  David   18     88
4    Eva   20     92

Students aged 18:
print(df[df["Age"] == 18])
Output:

    Name  Age  Marks
0  Alice   18     85
3  David   18     88

Multiple conditions (Marks > 85 and Age > 18):
print(df[(df["Marks"] > 85) & (df["Age"] > 18)])
Output:
  Name  Age  Marks
1  Bob   19     90
4  Eva   20     92

4. Access Specific Cell (Row + Column)
Using .loc[]:
print(df.loc[1, "Marks"])  # Output: 90
Using .iloc[]:
print(df.iloc[1, 2])  # Same result (row 1, column 2)

Summary Table:
Task	                	Code Example
Get column	       	 	df["Name"]
Get multiple columns		df[["Name", "Marks"]]
Get row by label		df.loc[2]
Get row by position		df.iloc[2]
Filter by condition		df[df["Marks"] > 85]
Filter by multiple conditions	df[(df["Marks"] > 85) & (df["Age"] > 18)]
Get cell (row + column)		df.loc[1, "Marks"] or df.iloc[1, 2]

1. What is the difference between .loc[] and .iloc[] in Pandas?
.loc[]	.iloc[]
Uses labels/index names	Uses integer positions
Example: df.loc[2, "Marks"]	Example: df.iloc[2, 2]
Safer when you know row/column labels	Used when working with numeric index only

2. How do you select a single column from a DataFrame?
df["Marks"]
Or:

df.Marks  # works if column name has no space or special character

3. How can you select multiple columns from a DataFrame?
Use a list of column names inside df[]:

df[["Name", "Marks"]]

4. How do you access a specific cell value from a DataFrame?
Using .loc[] (label-based):

df.loc[1, "Marks"]  # Row index 1, column 'Marks'
Using .iloc[] (position-based):
df.iloc[1, 2]  # Row 1, Column 2

5. How can you filter rows in a DataFrame based on a condition?
Example: Get students with marks > 85:

df[df["Marks"] > 85]

6. What is the output of df[df["Age"] > 18]? Explain it.
It filters and returns only those rows where the "Age" is greater than 18.

Example output:
  Name  Age  Marks
1  Bob   19     90
4  Eva   20     92

7. Can you filter a DataFrame using multiple conditions? How?
Yes. Use & for AND, | for OR, and wrap each condition in parentheses.

df[(df["Marks"] > 85) & (df["Age"] > 18)]  # AND condition
df[(df["Marks"] > 85) | (df["Age"] == 18)]  # OR condition

8. What does the & operator do in a filtering condition?
It checks if both conditions are True for a row.

df[(df["Marks"] > 85) & (df["Age"] > 18)]
Only rows where both conditions are satisfied will be returned.

9. What is the difference between df["Age"] == 18 and df.Age == 18?
Both do the same thing:

df["Age"] == 18  # Recommended (works always)
df.Age == 18     # Works only if column name has no spaces/special characters

Use df["Age"] for safe and consistent practice.

10. How do you select rows where a column value is in a list?
Use .isin() method:

df[df["Name"].isin(["Bob", "Eva"])]
Returns only rows where Name is either "Bob" or "Eva".

Chapter 5: Data Cleaning in Pandas
Data cleaning is about making raw data usable, correct, and consistent. Common tasks include handling missing data, fixing column names, and removing duplicates.

We'll use this sample data:
import pandas as pd
import numpy as np

data = {
    "Name": ["Alice", "Bob", "Charlie", "David", "Eva", "Bob"],
    "Age": [25, np.nan, 30, 22, np.nan, 25],
    "City": ["Delhi", "Mumbai", np.nan, "Chennai", "Delhi", "Mumbai"]
}

df = pd.DataFrame(data)
print(df)

Input DataFrame:
      Name   Age     City
0    Alice  25.0    Delhi
1      Bob   NaN   Mumbai
2  Charlie  30.0      NaN
3    David  22.0  Chennai
4      Eva   NaN    Delhi
5      Bob  25.0   Mumbai

1. Checking Missing Values
isnull() - Shows True for missing (NaN) values
df.isnull()
Output:

    Name    Age   City
0  False  False  False
1  False   True  False
2  False  False   True
3  False  False  False
4  False   True  False
5  False  False  False

notnull() - Opposite of isnull()
df.notnull()
Output:

    Name   Age  City
0   True  True  True
1   True  False True
2   True  True  False
3   True  True  True
4   True  False True
5   True  True  True

2. Handling Missing Values
fillna() - Fill missing values with default values
df_filled = df.fillna({"Age": 0, "City": "Unknown"})
print(df_filled)
Output:

      Name   Age     City
0    Alice  25.0    Delhi
1      Bob   0.0   Mumbai
2  Charlie  30.0  Unknown
3    David  22.0  Chennai
4      Eva   0.0    Delhi
5      Bob  25.0   Mumbai

dropna() - Remove rows with any missing values
df_dropped = df.dropna()
print(df_dropped)
Output:

    Name   Age     City
0  Alice  25.0    Delhi
3  David  22.0  Chennai
5    Bob  25.0   Mumbai

Use df.dropna(subset=["Age"]) to drop rows only if "Age" is missing.

3. Replacing Values
replace() - Replace specific values
df_replaced = df.replace({"Delhi": "New Delhi", "Bob": "Robert"})
print(df_replaced)
Output:
      Name   Age      City
0    Alice  25.0  New Delhi
1   Robert   NaN     Mumbai
2  Charlie  30.0        NaN
3    David  22.0    Chennai
4      Eva   NaN  New Delhi
5   Robert  25.0     Mumbai

4. Renaming Columns
rename() - Rename column names
df_renamed = df.rename(columns={"Name": "Student Name", "Age": "Student Age"})
print(df_renamed)
Output:

  Student Name  Student Age     City
0        Alice         25.0    Delhi
1          Bob          NaN   Mumbai
2      Charlie         30.0      NaN
3        David         22.0  Chennai
4          Eva          NaN    Delhi
5          Bob         25.0   Mumbai

5. Changing Data Types
astype() - Convert column type
df["Age"] = df["Age"].fillna(0)  # Fill NaN first
df["Age"] = df["Age"].astype(int)
print(df)
Output:

      Name  Age     City
0    Alice   25    Delhi
1      Bob    0   Mumbai
2  Charlie   30      NaN
3    David   22  Chennai
4      Eva    0    Delhi
5      Bob   25   Mumbai

6. Removing Duplicates
drop_duplicates() - Remove duplicate rows
df_no_duplicates = df.drop_duplicates()
print(df_no_duplicates)
Output:

      Name  Age     City
0    Alice   25    Delhi
1      Bob    0   Mumbai

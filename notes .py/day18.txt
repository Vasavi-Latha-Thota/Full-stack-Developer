Modules and User-Defined Modules

Introduction to Modules
What is a Module?
A module is a Python file (.py) that contains functions, classes, variables, and executable
code. Instead of writing everything in a single file, we can divide a program into multiple
modules. This makes the code easier to organize, reuse, and maintain.
Advantages of Modules
● Code Reusability
● Better Code Organization
● Reduces Code Duplication
● Easier Debugging
● Easier Maintenance
● Supports Team Collaboration

Importing Modules
Python provides several ways to import modules.
Import Entire Module
Syntax

import module_name

Example

import my_module
print(my_module.greet("Rahul"))

Import Specific Function
Syntax

from module_name import function_name

Example

from my_module import greet
print(greet("Rahul"))

Import Multiple Functions
Syntax

from module_name import function1, function2

Example

from math import sqrt, factorial
print(sqrt(25))
print(factorial(5))

Import Using an Alias
Syntax

import module_name as alias_name

Example

import my_module as mm

Python Module Search Path
Definition
When Python imports a module, it searches for that module in different locations.
Search Order
1. Current working directory
2. Built-in modules
3. Directories listed in sys.path

Python

Python

Add a Custom Path

import sys

The name Variable

Definition
Every Python file contains a special built-in variable called __name__. Python automatically
assigns a value to this variable depending on how the file is executed.
There are only two possible values.
● "__main__"
● Module name

if name == "main"

Definition
The statement

if __name__ == "__main__":

checks whether the current file is being executed directly. If the file is executed directly, the
condition becomes True. If the file is imported into another program, the condition becomes
False.
Syntax

if __name__ == "__main__":
statements

Example
my_module.py

def greet(name):
return f"Hello {name}"
if __name__ == "__main__":
print(greet("Alice"))

Why Do We Use if name == "main"?
● To prevent test code from running when the module is imported.
● To use the same file as both a standalone program and a reusable module.
● To improve code organization.
● To make modules reusable.

Input Formatting
Python's input() function is used to take input from the user during program execution. By
default, it returns a string. We often convert the input into int, float, list, tuple, set,
or dict as needed.

1. String Input
Use case: Entering a name, email, city, etc.

name = input("Enter your full name: ")
print(name)

Example:

Enter your full name: Ankit Sharma
Output: Ankit Sharma

2. Integer Input
Use case: Age, quantity, mobile number, number of items in cart.

quantity = int(input("Enter the number of items: "))
print(quantity)

Example:

Enter the number of items: 5
Output: 5

3. Float Input
Use case: Price, temperature, discount, rating.

price = float(input("Enter the product price: "))
print(price)

Example:

Enter the product price: 299.99
Output: 299.99

4. Input as List (Space-separated)
Use case: List of names, marks, or product IDs.

names = input("Enter employee names (space-separated):
").split()
print(names)

Example:

Enter employee names (space-separated): Ankit Ravi Sneha
Output: ['Ankit', 'Ravi', 'Sneha']

5. Input as List (Comma-separated)
Use case: Tags, emails, product categories.

tags = input("Enter tags (comma-separated): ").split(',')
print(tags)

6. List of Integers
Use case: Marks, product prices, IDs.

marks = list(map(int, input("Enter marks: ").split()))
print(marks)

Example:

Enter marks: 89 76 94 82
Output: [89, 76, 94, 82]

7. List of Floats
Use case: Sensor readings, weights, product prices.

weights = list(map(float, input("Enter weights: ").split()))
print(weights)

Example:

Enter weights: 55.6 62.1 70.3
Output: [55.6, 62.1, 70.3]

8. Tuple Input
Use case: Coordinates, dimensions (length, width, height).

dimensions = tuple(map(int, input("Enter length, width,
height: ").split()))
print(dimensions)

Example:

Enter length, width, height: 10 20 15
Output: (10, 20, 15)

9. Set Input
Use case: Selected image IDs where duplicates must be removed (e.g., in a photo-sharing
app).

selected_ids = set(map(int, input("Enter selected image IDs:
").split()))
print(selected_ids)

Example:

Enter selected image IDs: 101 102 103 101 104
Output: {101, 102, 103, 104}

10. Dictionary Input using eval()
Use case: When entering structured data like configuration settings or user profiles.

profile = eval(input("Enter user profile as a dictionary: "))
print(profile)

Example:

Enter user profile as a dictionary: {'name': 'Ravi', 'age':
30, 'role': 'admin'}
Output: {'name': 'Ravi', 'age': 30, 'role': 'admin'}

Note: Only use eval() when input is trusted.

11. Multiple Inputs with Unpacking
Use case: Login form or payment details.

username, password = input("Enter username and password:
").split()
print("Username:", username)
print("Password:", password)

Example:

Enter username and password: user01 mypassword123
Username: user01
Password: mypassword123

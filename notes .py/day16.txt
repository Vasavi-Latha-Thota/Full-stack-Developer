List Comprehension

1. What is a List?
In Python, a list is a collection of items. Lists are written using square brackets [].
Example:

numbers = [1, 2, 3, 4]
names = ["Alice", "Bob"]
mixed = [1, "hello", True, 3.5]

2. What is a List Comprehension?
A list comprehension is a short and powerful way to create new lists by using a loop in one
line.

3. List Comprehension Syntax

[expression for item in iterable if condition]

Explanation:
● expression: what to do with the item (e.g., transform or return it)
● item: the variable name for each value in the iterable
● iterable: the collection you’re looping over (e.g., a list)
● condition (optional): filter to include only matching items

4. Basic Examples
a. Square numbers in a range:

squares = [x * x for x in range(6)]
print(squares)
# Output: [0, 1, 4, 9, 16, 25]

b. Filter even numbers:

numbers = [1, 2, 3, 4, 5, 6]
evens = [n for n in numbers if n % 2 == 0]
print(evens)
# Output: [2, 4, 6]

c. Uppercase a list of strings:

names = ["alice", "bob", "charlie"]
upper_names = [name.upper() for name in names]
print(upper_names)
# Output: ['ALICE', 'BOB', 'CHARLIE']

7. Nested List Comprehension
Example: Flatten a list of product color options

products_colors = [
{"name": "Laptop", "colors": ["Silver", "Black"]},
{"name": "Phone", "colors": ["Gold", "Blue"]}
]
all_colors = [color for product in products_colors for color
in product["colors"]]
# ['Silver', 'Black', 'Gold', 'Blue']

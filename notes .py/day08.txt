LISTS

Introduction to Lists
A list is an ordered, mutable collection used to store multiple values in a single variable.
Lists are created using: [] or list()
Example:

numbers = [10, 20, 30]
names = ["Ravi", "Teja", "Ankit"]
mixed = [10, "Python", 5.5, True]

LIST PROPERTIES

Property Description
Ordered Elements maintain insertion order
Mutable Elements can be modified
Indexed Elements can be accessed using index
Iterable Can iterate using loops
Allows Duplicates Duplicate values are allowed
Dynamic Size Size can grow or shrink
Heterogeneous Can store different datatypes

Method Description Example

3. SEARCH METHODS

4. SORTING & REVERSING METHODS
Method Description Example

sorted() Returns sorted new list sorted(lst)

TUPLES

Introduction to Tuples
A tuple is an ordered, immutable collection used to store multiple values in a single variable.
Tuples are created using parentheses ( ) or tuple()

numbers = (10, 20, 30)
names = ("Ravi", "Teja", "Ankit")
mixed = (10, "Python", 5.5, True)

TUPLE PROPERTIES
Property Description
Ordered Elements maintain insertion order
Immutable Elements cannot be added, removed, or modified directly
Iterable Can iterate through elements using loops
Allows Duplicates Duplicate values are allowed
Heterogeneous Can store different datatypes
Supports Nested Objects Can contain tuples, lists, sets, dictionaries, etc.
Mutable Objects Can
Change

If a tuple contains mutable objects (like lists), those objects can
be modified

Faster Than Lists Generally consumes less memory and provides faster access

than lists

TUPLE OPERATIONS

1. Concatenation (+)
Used to join tuples.

a = (1, 2)
b = (3, 4)
print(a + b) # (1, 2, 3, 4)

2. Repetition (*)
Used to repeat tuple elements.

print((1, 2) * 3) # (1, 2, 1, 2, 1, 2)

Python

Python

Python
3. Indexing
Used to access elements using index positions.

data = (10, 20, 30, 40)
print(data[0]) # 10
print(data[-1]) # 40

4. Slicing
Used to extract part of a tuple.
Syntax:

tuple[start:end:step]

Example:

data = (10, 20, 30, 40, 50)
print(data[1:4]) # (20, 30, 40)
print(data[::-1]) # (50, 40, 30, 20, 10)

5. Membership Operators
Checks whether an element exists.

data = (10, 20, 30)
print(20 in data) # True
print(100 not in data) # True

Python
BUILT-IN TUPLE FUNCTIONS
Function Description Example
len() Returns tuple length len((1,2,3)) → 3
max() Returns largest element max((10,20,5)) → 20
min() Returns smallest element min((10,20,5)) → 5
sum() Returns sum of numeric elements sum((1,2,3)) → 6
sorted() Returns sorted list sorted((3,1,2)) → [1,2,3]
tuple() Converts iterable to tuple tuple("abc") → ('a','b','c')
any() Returns True if at least one value is True any((0,0,1)) → True
all() Returns True if all values are True all((1,2,3)) → True

TUPLE METHODS
Since tuples are immutable, they provide only two built-in methods.
Method Description Example
count() Counts occurrences of an element (1,2,2,3).count(2) → 2
index() Returns first occurrence index (10,20,30).index(20) → 1

TUPLE PACKING
Storing multiple values into a tuple automatically.

data = 10, 20, 30
print(data) # (10, 20, 30)

TUPLE UNPACKING
Extracting tuple elements into variables.

data = (10, 20, 30)
a, b, c = data

NESTED TUPLES
A tuple inside another tuple is called a nested tuple.

print(data[0]) # (1, 2)
print(data[1][1]) # 4

Tuple elements cannot be modified.

MUTABLE OBJECTS INSIDE TUPLES
Although tuples are immutable, mutable objects stored inside them can still be modified.

data = (10, [20, 30], 40)
data[1].append(50)
print(data)
# (10, [20, 30, 50], 40)
Explanation:

data[0] = 100

Not Allowed

data[1].append(50)

Allowed
Because the tuple itself is immutable, but the list inside it is mutable.

WHY USE TUPLES?
● Data should not be modified.
● Better memory efficiency.
● Faster than lists.
● Useful for fixed collections of values.
● Commonly used for coordinates, dimensions, and database records.
● Supports packing and unpacking.
Example:

location = (17.3850, 78.4867)
dimensions = (10, 20, 5)
